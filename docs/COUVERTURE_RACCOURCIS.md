# Raccourcis et commandes — V3

Source typée : `src/content/shortcuts.ts` ; interface : `/raccourcis`.

26 commandes documentées pour Windows et applications de bureau Word, Excel, PowerPoint et Outlook classique. Recherche par tâche, filtres logiciel, famille et version. Le périmètre initial a un seul OS et un seul niveau ; ils sont annoncés comme tels plutôt que proposés comme filtres sans effet. Chaque fiche comporte fonction, contexte, alternative souris, avertissement, version, date de consultation et lien Microsoft.

Chaque carte ouvre un clavier d’entraînement : choisir les touches, vérifier, lire la correction, recommencer en changeant la sélection. Aucun raccourci du système n’est intercepté globalement et aucun logiciel installé n’est piloté. Le laboratoire de capture ajoute un scénario contextualisé.

Sources consultées le 25 novembre 2026 :

- https://support.microsoft.com/fr-fr/accessibility/windows/keyboard-shortcuts-in-windows
- https://support.microsoft.com/fr-fr/accessibility/word/keyboard-shortcuts-in-word
- https://support.microsoft.com/fr-fr/accessibility/excel/keyboard-shortcuts-in-excel
- https://support.microsoft.com/fr-fr/accessibility/powerpoint/use-keyboard-shortcuts-to-create-powerpoint-presentations
- https://support.microsoft.com/fr-fr/accessibility/outlook/keyboard-shortcuts-for-outlook

La traduction française Microsoft présente des variations historiques concernant le gras dans Word. Aucune équivalence universelle Ctrl+G/Ctrl+B n’a été publiée dans le catalogue ; le ruban reste l’alternative conseillée. Une consultation de documentation n’est pas un test dans toutes les versions installées. Mac, Web et commandes avancées restent à enrichir. Pas de copie intégrale des listes Microsoft ni de promesse « tous les raccourcis ».
