## Votre objectif

Dupliquer un document dans le bon dossier et vérifier sa destination.

## Les étapes

### 1. Ouvrir vos fichiers

Appuyez sur Windows + E. Repérez le document dans son dossier.

### 2. Choisir l’action

Sélectionnez le fichier. Ctrl + C le copie ; Ctrl + X prépare son déplacement.

### 3. Choisir la destination

Ouvrez le dossier de destination. Vérifiez son nom dans la barre d’adresse.

### 4. Coller et vérifier

Appuyez sur Ctrl + V. Ouvrez le document obtenu avant de supprimer un original.

## Le bon réflexe

Lors d’un déplacement entre emplacements, vérifiez le résultat avant de fermer l’Explorateur. Ne déplacez pas les fichiers système.

## Si votre écran est différent

Les intitulés peuvent varier selon la langue, la version et les règles de votre organisation. Vérifiez votre version dans les informations du logiciel. Consultez la documentation liée avant toute modification d’un fichier important.
