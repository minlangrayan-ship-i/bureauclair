## Votre objectif

Créer un courrier lisible et conserver une version modifiable.

## Les étapes

### 1. Préparer le document

Créez un document vierge ou un modèle autorisé par votre organisation.

### 2. Structurer le courrier

Séparez destinataire, date, objet, corps et signature avec des paragraphes.

### 3. Relire

Contrôlez les noms, les dates et les engagements avant de partager.

### 4. Enregistrer

Choisissez un dossier autorisé et un nom explicite. Conservez le DOCX pour les corrections.

## Le bon réflexe

Évitez les suites d’espaces pour aligner le texte : elles se décalent sur un autre poste.

## Si votre écran est différent

Les intitulés peuvent varier selon la langue, la version et les règles de votre organisation. Vérifiez votre version dans les informations du logiciel. Consultez la documentation liée avant toute modification d’un fichier important.
