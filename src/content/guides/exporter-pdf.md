## Votre objectif

Produire un PDF de diffusion tout en gardant le document source.

## Les étapes

### 1. Enregistrer le source

Conservez d’abord une copie DOCX modifiable.

### 2. Choisir le format

Utilisez Fichier puis Enregistrer sous ou Exporter et sélectionnez PDF.

### 3. Contrôler les options

Vérifiez les pages et l’inclusion éventuelle des marques de révision.

### 4. Ouvrir le PDF

Relisez le PDF créé : pagination, liens, tableaux et caractères.

## Le bon réflexe

Le PDF ne garantit pas l’absence de données personnelles ou de commentaires.

## Si votre écran est différent

Les intitulés peuvent varier selon la langue, la version et les règles de votre organisation. Vérifiez votre version dans les informations du logiciel. Consultez la documentation liée avant toute modification d’un fichier important.
