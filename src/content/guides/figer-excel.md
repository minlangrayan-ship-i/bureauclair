## Votre objectif

Lire un tableau long sans perdre les noms des colonnes.

## Les étapes

### 1. Revenir au début

Placez les en-têtes dans la première ligne du tableau.

### 2. Figer

Dans Affichage > Figer les volets, choisissez Figer la ligne supérieure.

### 3. Tester et annuler

Faites défiler les lignes. Pour annuler, utilisez Libérer les volets dans le même menu.

## Le bon réflexe

Pour figer plusieurs lignes, le choix de la cellule active est déterminant : consultez la source.

## Si votre écran est différent

Les intitulés peuvent varier selon la langue, la version et les règles de votre organisation. Vérifiez votre version dans les informations du logiciel. Consultez la documentation liée avant toute modification d’un fichier important.
