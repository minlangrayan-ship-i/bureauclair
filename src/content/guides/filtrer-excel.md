## Votre objectif

Afficher une partie du tableau sans supprimer les autres données.

## Les étapes

### 1. Ouvrir le filtre

Cliquez sur la flèche de l’en-tête Statut de votre tableau.

### 2. Choisir les valeurs

Gardez les statuts utiles, puis validez.

### 3. Repérer les lignes masquées

Vérifiez l’icône de filtre pour savoir qu’une sélection est active.

### 4. Tout réafficher

Ouvrez à nouveau la flèche puis effacez le filtre de cette colonne.

## Le bon réflexe

Une ligne masquée par un filtre reste dans le fichier et peut être partagée.

## Si votre écran est différent

Les intitulés peuvent varier selon la langue, la version et les règles de votre organisation. Vérifiez votre version dans les informations du logiciel. Consultez la documentation liée avant toute modification d’un fichier important.
