## Votre objectif

Distinguer le contenu projeté des notes destinées au présentateur.

## Les étapes

### 1. Ouvrir les notes

Sélectionnez une diapositive et affichez le volet Notes.

### 2. Préparer les repères

Ajoutez vos points de parole sans recopier tout le texte.

### 3. Tester le mode Présentateur

Utilisez le matériel prévu et vérifiez quel écran voit les notes.

### 4. Contrôler le partage

Avant une visioconférence, partagez uniquement la fenêtre souhaitée.

## Le bon réflexe

Une capture ou un partage de tout l’écran peut montrer vos notes privées.

## Si votre écran est différent

Les intitulés peuvent varier selon la langue, la version et les règles de votre organisation. Vérifiez votre version dans les informations du logiciel. Consultez la documentation liée avant toute modification d’un fichier important.
