## Votre objectif

Retenir trois gestes pour naviguer plus facilement au clavier.

## Les étapes

### 1. Changer de fenêtre

Maintenez Alt puis appuyez sur Tab pour sélectionner une autre application.

### 2. Retrouver le bureau

Windows + D affiche le bureau. La même combinaison rétablit vos fenêtres.

### 3. Verrouiller votre session

Windows + L verrouille le PC lorsque vous vous absentez.

## Le bon réflexe

Enregistrez votre travail régulièrement : verrouiller ne remplace pas une sauvegarde.

## Si votre écran est différent

Les intitulés peuvent varier selon la langue, la version et les règles de votre organisation. Vérifiez votre version dans les informations du logiciel. Consultez la documentation liée avant toute modification d’un fichier important.
