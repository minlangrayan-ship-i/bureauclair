## Votre objectif

Distinguer une copie locale d’une sauvegarde Windows liée au cloud.

## Les étapes

### 1. Identifier les règles

Demandez où les documents professionnels doivent être conservés.

### 2. Examiner Sauvegarde Windows

Ouvrez l’application et identifiez les éléments proposés et le compte utilisé.

### 3. Choisir consciemment

N’activez une synchronisation de dossiers que si son stockage distant est autorisé.

### 4. Contrôler la restauration

Sur une copie non sensible, vérifiez que le fichier peut être récupéré.

## Le bon réflexe

Synchronisation et sauvegarde ne sont pas équivalentes : une suppression peut être synchronisée.

## Si votre écran est différent

Les intitulés peuvent varier selon la langue, la version et les règles de votre organisation. Vérifiez votre version dans les informations du logiciel. Consultez la documentation liée avant toute modification d’un fichier important.
