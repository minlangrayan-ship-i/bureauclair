## Votre objectif

Rendre les titres cohérents et faciliter la navigation dans un document.

## Les étapes

### 1. Repérer les niveaux

Distinguez le titre général, les sections et les sous-sections.

### 2. Appliquer un style

Dans Accueil, sélectionnez un paragraphe puis le style Titre 1 ou Titre 2 adapté.

### 3. Contrôler la structure

Ouvrez le volet de navigation et vérifiez l’ordre des titres.

### 4. Relire le résultat

Vérifiez les sauts de page et les titres isolés avant l’envoi.

## Le bon réflexe

Un texte simplement agrandi n’est pas un titre structuré pour un lecteur d’écran.

## Si votre écran est différent

Les intitulés peuvent varier selon la langue, la version et les règles de votre organisation. Vérifiez votre version dans les informations du logiciel. Consultez la documentation liée avant toute modification d’un fichier important.
