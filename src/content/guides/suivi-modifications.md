## Votre objectif

Afficher les corrections et les examiner une par une.

## Les étapes

### 1. Préserver une copie

Enregistrez une version de travail avant la relecture.

### 2. Activer le suivi

Dans Révision, activez Suivi des modifications puis corrigez le texte.

### 3. Examiner

Parcourez les modifications et acceptez ou refusez chacune selon son sens.

### 4. Vérifier avant l’envoi

Affichez toutes les marques pour repérer les commentaires ou modifications encore présents.

## Le bon réflexe

Masquer les marques ne supprime pas les corrections enregistrées.

## Si votre écran est différent

Les intitulés peuvent varier selon la langue, la version et les règles de votre organisation. Vérifiez votre version dans les informations du logiciel. Consultez la documentation liée avant toute modification d’un fichier important.
