## Votre objectif

Classer les dossiers par échéance en gardant les colonnes associées.

## Les étapes

### 1. Préserver le fichier

Enregistrez une copie de votre classeur avant un premier essai.

### 2. Sélectionner le tableau

Cliquez dans le tableau complet, avec ses en-têtes.

### 3. Choisir le tri

Dans l’en-tête Échéance, choisissez un tri de la plus ancienne à la plus récente.

### 4. Contrôler

Vérifiez que chaque responsable correspond toujours au bon dossier.

## Le bon réflexe

Si Excel demande d’étendre la sélection, vérifiez que toutes les colonnes liées sont incluses.

## Si votre écran est différent

Les intitulés peuvent varier selon la langue, la version et les règles de votre organisation. Vérifiez votre version dans les informations du logiciel. Consultez la documentation liée avant toute modification d’un fichier important.
