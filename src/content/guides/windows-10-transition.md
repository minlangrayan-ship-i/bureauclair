## Votre objectif

Faire l’inventaire de son poste avant une migration vers Windows 11.

## Les étapes

### 1. Vérifier le poste

Notez la version Windows et les logiciels indispensables sans publier les identifiants du PC.

### 2. Préparer les documents

Vérifiez la sauvegarde et les accès avec votre service informatique.

### 3. Contrôler la compatibilité

Faites vérifier la compatibilité Windows 11 et celle de vos logiciels métier.

### 4. Planifier le passage

Prévoyez un créneau, les mises à jour et un contrôle après migration.

## Le bon réflexe

Le support standard a pris fin le 14 octobre 2025. Les programmes ESU et leurs conditions sont distincts : consultez Microsoft et votre organisation.

## Si votre écran est différent

Les intitulés peuvent varier selon la langue, la version et les règles de votre organisation. Vérifiez votre version dans les informations du logiciel. Consultez la documentation liée avant toute modification d’un fichier important.
